# 기능 명세: 블랙홀 키우기 (가칭) — PC 2D 인크리멘탈 클리커 코어

> 인수인계 문서(`HANDOFF.md`)에서 **테스트 가능한 규칙만 추출·재구성**한 명세다.
> 현재 단계는 HTML + JavaScript 프로토타입(최종 목표 엔진은 Unity 2D).
> **수식의 "모양"(합산/곱산, 버킷 분리, 크리 위치)은 확정**이므로 그대로 검증한다.
> 난이도·밸런싱 상수(적 체력·쿼터·제한시간 등)는 **미확정 임시값**이며 `[가정]`으로 표기하고, 확정이 필요한 항목은 `Spec Issues`에 기록한다.
> 별도 명시가 없으면 기준 상태는 **강화 노드 0개, 코드 초기값**(baseAttack=10, flatBonus=0, multBucketPercent=0, critChance=0, critMult=2.0, attackInterval=1.0초, goldMultPercent=0, cursorRadius=60px)이다.

---

## 1. 코어 게임플레이 루프
- 한 웨이브는 "제한시간 T 안에 목표 처치 수 Q 달성" 검사다.
- 웨이브 시작 → 커서를 적 위에 올려두면 커서 범위 안의 적이 공격주기마다 자동 피격 → 적 처치 시 골드 획득.
- 제한시간 T 안에 목표 수 Q를 달성하면: 강화 화면으로 전환 → 다음 웨이브 시작.
- 제한시간 T가 만료될 때까지 Q를 달성하지 못하면: 게임오버(쿼터형 실패).
- 게임오버 시 보유 골드와 구매한 강화는 **유지된 채** 1웨이브부터 재시작한다.
- 강화 효과는 웨이브·게임오버와 무관하게 **영구 유지**된다.
- 총 웨이브 수 `TOTAL_WAVES = 15`이며 마지막 웨이브는 보스 웨이브다. `[가정]` (10~20 중 15로 잡음)

## 2. 조작 — 커서 호버 자동 타격
- 플레이어는 마우스 커서를 적 위에 올려두기만 한다. 클릭 연타는 하지 않으며, 클릭해도 추가 타격이 발생하지 않는다.
- 커서 중심에서 반경 `cursorRadius`(기본 60px) 이내에 있는 적만 타격 대상이다. 범위 밖의 적은 피격되지 않는다.
- 타격은 `attackInterval`(기본 1.0초)마다 1회 발생한다. 즉 초당 타격 횟수 = `1 / attackInterval`.
- 범위 안에 적이 여러 마리면 각 적이 공격주기마다 타격을 받는다.
- 커서를 어떤 적에도 올려두지 않으면 타격이 발생하지 않는다.

## 3. 골드 획득
- 적을 처치하면 골드를 얻는다.
- 처치당 골드는 골드 획득량 노드에 의해 `× (1 + goldMultPercent / 100)` 로 증가한다.
- 골드는 강화 노드 구매에만 사용한다.

## 4. 공격력 공식 (버킷 분리)
- 최종 공격력 = `(baseAttack + flatBonus) × (1 + multBucketPercent / 100)`
- `flatBonus`(고정합 버킷): 고정 공격력 노드가 `+N` 더하는 자리. 초반 체감 성장 담당.
- `multBucketPercent`(배수 버킷): 배수 계열 노드가 `%`를 더하는 자리.
- 크리티컬은 이 공식 안에 포함하지 않는다(§6 참조).

## 5. 배수 버킷 — "합산" 방식
- 여러 배수 노드의 %는 **전부 더한다(곱하지 않는다)**.
  - 예: 노드 A 풀강(+15%) + 노드 B 풀강(+15%) → `1 + 0.30 = ×1.30` (`1.15 × 1.15` 아님).
- 배수 노드는 레벨당 `+3%`, 한 노드는 `0/5`레벨이라 풀강 시 `+15%`.
- 배수 버킷 합계 상한: `multBucketPercent ≤ 200` (= 최종 배수 ×3.0). 구매 시 `min(200, multBucketPercent + 3)` 로 클램프된다.
- 상한에 도달한 뒤 추가 배수 노드를 구매해도 `multBucketPercent`는 200을 넘지 않는다.

## 6. 크리티컬 (공식 바깥에서 곱해짐)
- 실효 DPS = `최종공격력 × (1 / attackInterval) × (1 + critChance × (critMult − 1))`.
- 타격이 실제로 적용되는 시점에 별도로 굴린다: 난수 < `critChance` 이면 크리, 이때 피해 = `타격피해 × critMult`.
- `critMult`는 초기값 `2.0` 고정이다.
- `critChance` 범위는 `0.0 ~ 0.75`. 상한이 반드시 존재해야 하며(없으면 100% 초과로 상시 발동), 코드 상한은 0.75다. `[가정]` 권장 최종 상한 60~75% (미확정).
- `critChance`가 상한에 도달한 뒤 크리 확률 노드를 더 구매해도 0.75를 넘지 않는다.

## 7. 강화 노드 목록 (총 8종)
- 모든 노드는 웨이브 종료 후 강화 화면에서 골드로 구매하며, 효과는 영구 유지된다.

| # | 노드 | 효과 | 규칙 |
|---|---|---|---|
| 1 | 고정 공격력 | `flatBonus += 5` | 가장 단순. 강화 시스템 검증용 첫 노드 |
| 2 | 공격력 배수 | `multBucketPercent += 3` | 레벨당 +3%, 노드 0/5레벨(풀강 +15%), 버킷 합계 상한 200(×3.0) |
| 3 | 공격주기 | `attackInterval` 감소 | 초당 타격 횟수 ↑ = DPS 직결. `[가정]` 감소량·하한 미정의 |
| 4 | 골드 획득량 | `goldMultPercent += %` | 처치당 골드 증가. `[가정]` 증가량 미정의 |
| 5 | 크리티컬 확률 | `critChance += %` | 상한 0.75(=75%). `[가정]` 레벨당 증가량 미정의 |
| 6 | 크리티컬 배수 | `critMult` 증가 | 초기 ×2.0 고정 권장. `[가정]` 노드화 여부·증가량 미정의 |
| 7 | 웨이브 시간 | 제한시간 `+초` | **강한 상한 필수**. `[가정]` 예: 최대 +5초, 노드 3개까지 |
| 8 | 커서 범위 | `cursorRadius` 확대 | 맨 마지막에 구현·밸런싱. `[가정]` 확대량·상한 미정의 |

## 8. 웨이브 시간 노드 상한
- 실패 조건이 "제한시간 내 쿼터 달성"이므로, 제한시간을 늘리는 노드는 DPS를 올리지 않고도 게이트를 우회할 수 있어 **강한 상한**을 둔다.
- `[가정]` 상한 예시: 누적 최대 `+5초`, 구매 가능 노드 수 `3개`. 상한 도달 후 추가 구매는 불가하다.
- 이 노드는 "게이트 돌파용"이 아니라 "빠듯할 때 숨통 트기용"이다.

## 9. 강화 구매 / 골드 소비
- 노드 구매 시 해당 노드 비용만큼 골드를 소모한다.
- 보유 골드 < 노드 비용이면 구매할 수 없고, 골드·노드 레벨은 변하지 않는다.
- 노드가 최대 레벨(또는 버킷 상한)에 도달하면 더 구매할 수 없다.
- `[가정]` 노드별 비용과 비용 증가 곡선은 미정의다.

## 10. 밸런싱 설정 (waveConfig — 전부 임시값, 미확정)
- `[가정]` `baseQuota = 8` (1웨이브 목표 처치 수)
- `[가정]` `baseTimeLimit = 20` (1웨이브 제한시간, 초)
- `[가정]` `baseEnemyHp = 10` (1웨이브 적 1마리 체력)
- `[가정]` `enemyHpAt(wave) = baseEnemyHp × 1.3^(wave−1)` (예시 곡선)
- `[가정]` `quotaAt(wave) = baseQuota + (wave−1) × 2` (예시)
- `[가정]` `timeAt(wave) = baseTimeLimit` (예시: 전 웨이브 고정)
- 난이도 곡선은 피보나치식 지수 증가(1,2,3,5,8,13,21…) 계열로 구상 중이나 확정되지 않았다.
- 조절 손잡이는 웨이브별 쿼터 Q, 적 체력, 제한시간 T 세 가지다.

## 11. UI 표시
- 상단 중앙: 현재 웨이브 수 + 남은 제한시간.
- 좌측 상단: 현재 보유 골드.
- `[가정]` (제안) 상단에 쿼터 진행도(예: `6 / 10`) 표기.
- 웨이브 종료 시 강화 화면(노드 목록)을 노출한다.

## 12. 설계 제약 (검증 대상)
- 게임 배속 기능은 없다.
- 튜토리얼은 없다(가벼운 도움말만 출시 후 검토).
- 초반 답답함(노드 0개 상태에서 적이 느리게 죽음)은 **의도된 설계이며 버그가 아니다**.
- 강화가 충분히 쌓이면 초반 웨이브는 1초 내로 처리되도록 스케일을 잡는다.
- 스토리·캐릭터는 없다.
